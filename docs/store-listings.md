## Short description (all stores, 132 characters or fewer)

Strips tracking parameters and share IDs from links, in the address bar and when you copy or share.

## Long description

Sites like X, Amazon and YouTube quietly add IDs to every link which can be used to see who shared what, and from which device. Clean Links removes them.

WHAT IT DOES
- Cleans the address bar: tracking parameters are removed from the address as soon as the page opens, so they don't end up in your history, bookmarks or the links you share.
- Cleans Copy link and Share buttons: you get a tidy URL, ready to paste to a friend.
- Cleans links on the page when you hover or right-click them.
- Leaves useful parts alone: search terms, video timestamps and product variants are kept so links still work.

WORKS ON
X (Twitter), Amazon, YouTube, Instagram, Facebook, Reddit, LinkedIn, TikTok and Google search, plus common ad-click IDs (utm_*, fbclid, gclid, msclkid and more) on every site.

CONTROL
One switch turns it off. Pause any single site from the toolbar popup if a link ever needs its parameters.

PRIVATE BY DESIGN
No accounts, no analytics and no network requests of its own. Everything happens on your device. Free and open source (MIT): https://github.com/arrhen/clean-links-safari

LIMITS
Short links created by a site itself (such as t.co or amzn.to) can't be cleaned, because the tracking ID is stored on their server.

## Chrome Web Store and Edge Add-ons

- **Category:** Productivity (Chrome), Productivity or Privacy tools (Edge)
- **Single purpose:** Removes tracking parameters from web addresses and shared links.
- **Permission justifications**
  - `declarativeNetRequest` and access to all websites: to rewrite the address of any page to remove tracking parameters (where the browser supports it, before the request is sent). Tracking parameters can appear on any site.
  - `storage`: to save the user's on/off switch and the list of sites they paused, locally in the browser.
  - Content scripts on all pages: to clean links when the user presses Copy link or Share, and to tidy the address bar if a page adds tracking after it loads.
- **Remote code:** No. All code is packaged in the extension.
- **Data usage:** collects none of the listed data types. Certify that data is not sold, not used for unrelated purposes, and not used for creditworthiness.
- **Upload:** `dist/clean-links-chrome-<version>.zip` (Edge: `dist/clean-links-edge-<version>.zip`).
